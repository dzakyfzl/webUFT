# Catatan loop implementasi

Batas pengguna: maksimum 20 loop. Satu loop adalah satu siklus audit → perubahan → verifikasi, bukan satu tool call. Penghitung kumulatif lintas turn. Pada loop 20 berhenti dan laporkan cakupan yang terbukti serta sisa pekerjaan; jangan menandai seluruh goal selesai jika persyaratan belum terbukti.

## Perluasan P1 atas instruksi pengguna

Batch P0 di atas tetap berakhir pada 20/20. Pengguna kemudian meminta seluruh P1 serta menyetujui aturan produk dan migrasi tambahan/test rollback. Cakupan baru F11–F18 dicatat terpisah, tanpa mereset angka P0.

- Migrasi 0002_p1 ditambahkan setelah backup owner-only dan preflight. Percobaan awal rollback karena nama FK bertabrakan; constraint diperjelas sebelum migrasi berhasil. Head lokal 0002_p1: 30 tabel ERP, 21 tabel lain tetap.
- Backend/UI seluruh P1 ditulis dengan paket existing. Template section opsional dikoreksi melalui test; pemilik respons dipisah dari Inti pengelola konten. Generator short link existing dan kartu acara landing page disambungkan ke API P1 tanpa redesign.
- Suite akhir 103 test lulus (44 PostgreSQL). Discovery kelas import diperbaiki agar test P0 tidak dihitung dua kali. Versi form immutable, freeze arsip, privasi, idempotency, CSV/XLSX dan backup media tercakup.
- Browser production P1: 21 alur lulus, termasuk upload tepat 20 MiB/penolakan +1 byte, buku/peminjam eksternal/kembali rusak, realisasi/LPJ, hapus template, dropdown/bagian/urutan baru, stale form mempertahankan isian, pendaftaran anonim, Excel, publikasi landing page dan generator short link terautentikasi. Regresi P0 18 alur juga lulus.
- Screenshot 320/390/1440 diperiksa; tabel inventaris mobile diperbaiki agar tidak memecah nama/status per karakter. Build lulus; ESLint tanpa error, 3 warning existing di landing page. Restart server sempat memutus verifikasi; hasil akhir dicatat ulang di /tmp/webuft-p1-final-api.log dan /tmp/webuft-p1-final-browser.log.
- Belum membuktikan UAT manusia, Compose/VPS/HTTPS production, backup off-host atau restore DB+media operasional. Tidak ada deployment atau bootstrap akun operasional.
